# Gamblr - Prediction Market

A decentralized prediction market built on Arc Testnet.

## Features
- Connect wallet (MetaMask)
- Deposit USDC
- Place YES/NO bets on crypto predictions
- Claim winnings

## Smart Contract
- Contract Address: `0x18768Cd75D86E77CddE4B7DD3b222cCB604FDD5c`
- USDC Address: `0x3600000000000000000000000000000000000000`
- Network: Arc Testnet

## Getting Started
1. Install dependencies: `npm install`
2. Run development server: `npm run dev`
3. Connect your wallet and get testnet USDC from [Circle Faucet](https://faucet.circle.com/)

## Tech Stack
- React + TypeScript
- Vite
- Tailwind CSS
- ethers.js
- Express.js
